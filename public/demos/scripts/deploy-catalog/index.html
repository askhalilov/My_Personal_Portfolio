В mock режиме архив — это запись в каталоге. В real режиме — обычно это будет upload endpoint.
Под капотом mock симулирует этапы: RESOLVING_DNS → CONNECTING → CLEANING → UPLOADING → DONE.
Этот демо-сайт симулирует REST API (удобно для показов, пока backend не готов). В real режиме он будет делать fetch на ваш сервер.
