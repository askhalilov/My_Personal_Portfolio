# eco-monitoring-frontend

Статичный фронтенд (HTML/CSS/JS) для экрана **«Отчеты и аналитика»**.

## Как запустить
Вариант 1: просто открой `index.html` в браузере.

Вариант 2 (рекомендуется): через простой локальный сервер:
- VS Code → расширение Live Server → Open with Live Server
- или `python -m http.server 5173` (в папке проекта), затем открой `http://localhost:5173`

## Что внутри
- `index.html` — разметка
- `styles.css` — стили
- `main.js` — часы + демо-тосты на клики
